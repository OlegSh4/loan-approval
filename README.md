Этот проект посвящен анализу данных о кредитах с использованием различных методов машинного обучения для прогнозирования статуса кредита. ## Данные
Данные для анализа взяты из файлов `train.csv` и `test.csv`, которые содержат информацию о кредитах, включая возраст заемщика, доход, цель кредита и другие характеристики. Эти файлы должны быть размещены в корневой директории проекта.

## Предобработка данных
- **Кодирование категориальных признаков**: Категориальные переменные, такие как `person_home_ownership`, `loan_intent`, `loan_grade` и `cb_person_default_on_file`, были закодированы с использованием метода `pd.Categorical`.
- **Категоризация дохода**: Доход заемщика был разделен на три категории: "Низкий доход", "Средний доход" и "Высокий доход".
- **Вычисление вероятностей**: Для каждого `loan_grade` была вычислена вероятность положительного значения `loan_status`.

## Модели
В проекте используются следующие модели машинного обучения:
- **Логистическая регрессия**
- **Дерево решений**
- **Случайный лес**
- **KNN (метод ближайших соседей)**
- **CatBoost**

Каждая модель обучается на масштабированных данных и оценивается с использованием метрик AUC-ROC и точности.

## Результаты
Для каждой модели выполняется оценка производительности, включая построение ROC-кривых и вычисление AUC-ROC. Результаты прогнозов сохраняются в CSV файлы, такие как `test_knn_predictions.csv`, `test_logistic_regression_predictions.csv`, `test_dt_predictions.csv`, `test_rf_predictions.csv` и `test_catboost_predictions.csv`.

## Сравнение моделей
Сравнение моделей показало, что CatBoost демонстрирует наивысшую производительность с AUC-ROC 0.96, за ним следуют Random Forest (AUC-ROC 0.94), KNN (AUC-ROC 0.90), логистическая регрессия (AUC-ROC 0.89) и дерево решений (AUC-ROC 0.83).
